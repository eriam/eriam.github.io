3 SQL — SELECT, WHERE, ORDER BY

Objectifs de cette section
  • Lire et comprendre une requête SELECT simple
  • Filtrer des résultats avec WHERE
  • Trier les résultats avec ORDER BY

Rappel de cours

Une requête SELECT permet d'extraire des données d'une table.

-- Structure de base
SELECT colonne1, colonne2
FROM table
WHERE condition
ORDER BY colonne ASC;
-- Exemples concrets
SELECT nom, prenom FROM clients;
SELECT nom, prenom FROM clients WHERE ville = 'Lyon';
SELECT nom, prenom FROM clients WHERE ville = 'Lyon' ORDER BY nom ASC;

Quelques points clés :

  • SELECT * sélectionne toutes les colonnes (pratique mais à éviter en production).
  • WHERE filtre les lignes selon une condition. On peut combiner avec AND et OR.
  • ORDER BY trie : ASC (croissant, défaut) ou DESC (décroissant).

4 SQL — JOIN, GROUP BY et agrégats

Objectifs de cette section
  • Joindre deux tables avec INNER JOIN
  • Regrouper des résultats avec GROUP BY
  • Utiliser les fonctions COUNT, SUM, AVG, MAX, MIN

Rappel de cours

Joindre deux tables

Quand des données sont réparties sur plusieurs tables, on utilise JOIN pour les combiner :

SELECT commandes.id, clients.nom, commandes.montant
FROM commandes
INNER JOIN clients ON clients.id = commandes.id_client;

INNER JOIN ne renvoie que les lignes qui ont une correspondance dans les deux tables. On peut utiliser des alias pour raccourcir :

SELECT c.id, cl.nom, c.montant
FROM commandes c
INNER JOIN clients cl ON cl.id = c.id_client;

Regrouper et compter

GROUP BY regroupe les lignes qui ont la même valeur dans une colonne. On l'utilise avec des fonctions d'agrégation :

Fonction Rôle
COUNT(*) Compte le nombre de lignes
SUM(col) Somme les valeurs
AVG(col) Calcule la moyenne
MAX(col) Valeur maximale
MIN(col) Valeur minimale 
-- Nombre de commandes par client
SELECT id_client, COUNT(*) AS nb_commandes
FROM commandes
GROUP BY id_client;
-- Montant total des commandes par client
SELECT id_client, SUM(montant) AS total
FROM commandes
GROUP BY id_client;

Objectifs de cette section

Rappel de cours

Conditions

<?php
$note = 12;
if ($note >= 16) {
    $mention = "Très bien";
} elseif ($note >= 14) {
    $mention = "Bien";
} elseif ($note >= 12) {
    $mention = "Assez bien";
} elseif ($note >= 10) {
    $mention = "Passable";
} else {
    $mention = "Insuffisant";
}
echo $mention;  // Assez bien

Boucles

<?php
// foreach : parcourir un tableau
$fruits = ["pomme", "banane", "cerise"];
foreach ($fruits as $fruit) {
    echo $fruit . "\n";
}
// for : répéter N fois
for ($i = 0; $i < 5; $i++) {
    echo $i . "\n";  // 0, 1, 2, 3, 4
}
// while : tant que la condition est vraie
$compteur = 0;
while ($compteur < 3) {
    echo $compteur . "\n";
    $compteur++;  // 0, 1, 2
}

Fonctions

<?php
function calculerTva(float $prixHt, float $taux = 20.0): float {
    return $prixHt * (1 + $taux / 100);
}
echo calculerTva(100);      // 120.0  (taux par défaut = 20%)
echo calculerTva(100, 10);  // 110.0  (taux = 10%)

Points clés : - Les variables commencent par $ en PHP. - elseif s'écrit en un mot (pas else if, qui marche aussi mais est moins courant). - Les types peuvent être déclarés (PHP 7+) : float, int, string, bool.

6 POO PHP — classe, attribut, méthode

Objectifs de cette section
  • Comprendre ce qu'est une classe et un objet en PHP
  • Écrire une classe PHP avec __construct et $this
  • Instancier un objet et appeler ses méthodes

Rappel de cours

En programmation orientée objet (POO), on modélise le monde réel avec des classes. Une classe est un moule ; un objet est une instance de ce moule.

<?php
class Produit {
    public string $nom;
    public float  $prix;
    public function __construct(string $nom, float $prix) {
        $this->nom  = $nom;
        $this->prix = $prix;
    }
    public function afficher(): void {
        echo "{$this->nom} — {$this->prix} €\n";
    }
    public function appliquerRemise(float $pourcentage): float {
        return $this->prix * (1 - $pourcentage / 100);
    }
}
// Créer des objets (instances)
$clavier = new Produit("Clavier", 45);
$ecran   = new Produit("Écran", 299);
// Appeler des méthodes
$clavier->afficher();                        // Clavier — 45 €
echo $ecran->appliquerRemise(10) . "\n";    // 269.1

Points clés : - __construct est le constructeur : exécuté automatiquement lors du new. - $this-> désigne l'objet courant. Il faut l'utiliser pour accéder aux attributs depuis une méthode. - public rend l'attribut ou la méthode accessible depuis l'extérieur de la classe.

7 POO PHP — héritage et polymorphisme

Objectifs de cette section
  • Comprendre l'héritage en PHP avec extends
  • Appeler le constructeur parent avec parent::__construct()
  • Identifier le polymorphisme dans du code PHP

Rappel de cours

Héritage

L'héritage permet à une classe enfant de réutiliser les attributs et méthodes d'une classe parente, et d'en ajouter ou modifier.

<?php
class Animal {
    public string $nom;
    public function __construct(string $nom) {
        $this->nom = $nom;
    }
    public function parler(): string {
        return "...";
    }
    public function presentation(): string {
        return "Je m'appelle {$this->nom} et je dis : {$this->parler()}";
    }
}
class Chien extends Animal {       // Chien hérite de Animal
    public function parler(): string {
        return "Woof !";
    }
}
class Chat extends Animal {        // Chat hérite de Animal
    public function parler(): string {
        return "Miaou !";
    }
}
$rex  = new Chien("Rex");
$mimi = new Chat("Mimi");
echo $rex->presentation();   // Je m'appelle Rex et je dis : Woof !
echo $mimi->presentation();  // Je m'appelle Mimi et je dis : Miaou !

parent::

parent:: appelle une méthode de la classe parente :

<?php
class Employe {
    public string $nom;
    public float  $salaire;
    public function __construct(string $nom, float $salaire) {
        $this->nom     = $nom;
        $this->salaire = $salaire;
    }
}
class Manager extends Employe {
    public array $equipe;
    public function __construct(string $nom, float $salaire, array $equipe) {
        parent::__construct($nom, $salaire);  // appelle Employe::__construct
        $this->equipe = $equipe;              // attribut supplémentaire
    }
}

Polymorphisme

Des objets de types différents répondent à la même méthode, chacun à sa façon.

Activité 1 — Lire du code avec héritage

<?php
class Vehicule {
    public string $marque;
    public int    $vitesseMax;
    public function __construct(string $marque, int $vitesseMax) {
        $this->marque     = $marque;
        $this->vitesseMax = $vitesseMax;
    }
    public function description(): string {
        return "{$this->marque}, max {$this->vitesseMax} km/h";
    }
}
class Voiture extends Vehicule {
    public int $nbPortes;
    public function __construct(string $marque, int $vitesseMax, int $nbPortes) {
        parent::__construct($marque, $vitesseMax);
        $this->nbPortes = $nbPortes;

8 Gestion d'erreurs PHP — try/catch/throw

Objectifs de cette section
  • Comprendre ce qu'est une exception en PHP
  • Utiliser try/catch pour gérer les erreurs
  • Lancer une exception avec throw
  • Identifier les exceptions PHP courantes (PDOException, InvalidArgumentException)

Rappel de cours

Quand PHP rencontre une erreur grave, il lance une exception — le programme s'arrête si l'exception n'est pas interceptée.

<?php
// Sans gestion d'erreur : le programme plante
$tableau = [1, 2, 3];
echo $tableau[10];  // Notice, mais pas d'exception ici
// Avec PDO, les erreurs SQL lancent bien une exception :
$pdo = new PDO("mysql:host=localhost;dbname=inconnu", "root", "");
// → PDOException: SQLSTATE[HY000] Access denied...

Gérer une exception avec try/catch

<?php
try {
    $pdo = new PDO(
        "mysql:host=localhost;dbname=test;charset=utf8",
        "root", "",
        [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
    );
    echo "Connexion réussie.";
} catch (PDOException $e) {
    echo "Erreur BDD : " . $e->getMessage();
} finally {
    echo "Fin de la tentative de connexion.";
}
  • Le bloc try contient le code qui peut échouer.
  • Le bloc catch attrape l'exception si elle est lancée.
  • Le bloc finally est toujours exécuté (succès ou erreur).

Lancer une exception avec throw

<?php
function deposer(float $solde, float $montant): float {
    if ($montant <= 0) {
        throw new InvalidArgumentException("Le montant doit être positif.");
    }
    return $solde + $montant;
}
try {
    $nouveau = deposer(100, -50);
} catch (InvalidArgumentException $e) {
    echo "Erreur : " . $e->getMessage();
    // Erreur : Le montant doit être positif.
}

Couche 2 — Le DAO avec PDO

<?php
class ContactDAO {
    private PDO $pdo;
    public function __construct() {
        $this->pdo = new PDO(
            "mysql:host=localhost;dbname=contacts;charset=utf8",
            "root", "",
            [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
        );
    }
    public function creer(Contact $c): Contact {
        $stmt = $this->pdo->prepare(
            "INSERT INTO contacts (nom, prenom, email)
             VALUES (:nom, :prenom, :email)"
        );
        $stmt->execute([
            ':nom'    => $c->nom,
            ':prenom' => $c->prenom,
            ':email'  => $c->email,
        ]);
        $c->id = (int) $this->pdo->lastInsertId();
        return $c;
    }
    public function lireTous(): array {
        $stmt = $this->pdo->query(
            "SELECT id, nom, prenom, email FROM contacts ORDER BY nom"
        );
        return array_map(
            fn($r) => new Contact($r['nom'], $r['prenom'], $r['email'], $r['id']),
            $stmt->fetchAll(PDO::FETCH_ASSOC)
        );
    }
    public function supprimer(int $id): void {
        $stmt = $this->pdo->prepare("DELETE FROM contacts WHERE id = :id");
        $stmt->execute([':id' => $id]);
    }
}
